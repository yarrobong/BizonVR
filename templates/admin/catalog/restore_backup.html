Восстановление каталога из бэкапа

Инструкция

  1. Выберите ZIP файл с бэкапом каталога (созданный через действие "Создать полный бэкап каталога")
  2. При необходимости отметьте опцию "Очистить существующие данные" для полной замены каталога
  3. Нажмите "Восстановить" для начала процесса восстановления
⚠️ Внимание: Восстановление из бэкапа заменит все данные каталога. Рекомендуется создать новый бэкап перед восстановлением, если вы хотите сохранить текущее состояние.

Импорт каталога из JSON

Что поддерживается

  1. Файл должен быть обычным JSON в UTF-8 со структурой `{"models": {...}}`, совместимой с `backup.json`.
  2. После загрузки откроется экран проверки: там будут видны готовые записи, конфликты и предупреждения.
  3. Импорт работает по upsert-логике: обновляет совпавшие записи и создаёт недостающие, не удаляя лишние данные в БД.
  4. Опция «Проверить без записи» не пишет в PostgreSQL и сразу открывает review-экран.
Важно: поля с изображениями в JSON сейчас не импортируются. Они будут пропущены и попадут в предупреждения отчёта.

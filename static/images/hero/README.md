# Фото для Hero-блока (главная страница)

Положите сюда изображения для карусели в шапке главной страницы.

## Размеры и формат

| Параметр        | Значение |
|-----------------|----------|
| **Рекомендуемый размер** | **1920 × 600 px** |
| Соотношение сторон       | ~3.2 : 1 (широкий баннер) |
| Альтернатива             | 1920 × 800 px или 2560 × 800 px (Retina) |
| Формат                  | JPG или WebP |
| Вес                    | до 200–300 КБ на файл (после сжатия) |

## Почему такие размеры

- Блок hero на странице: **высота 400 px (мобильные) / 500 px (десктоп)**, ширина 100% экрана.
- Используется `background-size: cover` — картинка масштабируется и обрезается по границам блока.
- Широкое изображение (1920×600) хорошо смотрится на больших экранах; на узких обрежется по бокам, важное лучше держать по центру.

## Имена файлов

Используются 4 слайда. Имена файлов:

- `hero_1.jpg` — первый слайд  
- `hero_2.jpg` — второй слайд  
- `hero_3.jpg` — третий слайд  
- `hero_4.jpg` — четвёртый слайд  

После добавления файлов выполните: `python manage.py collectstatic`.

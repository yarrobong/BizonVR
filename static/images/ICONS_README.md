# Иконки сайта под разные устройства

Чтобы иконки корректно отображались во всех браузерах и при «Добавить на главный экран», нужны файлы в каталоге `static/images/` и ссылки на них в `templates/base.html` (уже добавлены).

## Какие файлы подготовить

| Файл | Размер | Назначение |
|------|--------|------------|
| `favicon.svg` | — | Уже есть. Вкладка браузера (современные браузеры). |
| `favicon-32x32.png` | 32×32 px | Вкладка, закладки (старые браузеры). |
| `favicon-16x16.png` | 16×16 px | Вкладка в маленьком размере. |
| `apple-touch-icon.png` | 180×180 px | iPhone/iPad: «Добавить на экран», иконка на главном экране. |
| `android-chrome-192x192.png` | 192×192 px | Android: иконка при добавлении на главный экран. |
| `android-chrome-512x512.png` | 512×512 px | Splash/иконка в списке приложений (PWA и др.). |

## Как получить PNG из текущего SVG

1. **Вручную (Figma/Sketch/Illustrator)**  
   Открыть `favicon.svg`, экспортировать в PNG в размерах 16, 32, 180, 192, 512.

2. **Онлайн**  
   Загрузить `favicon.svg` на [realfavicongenerator.net](https://realfavicongenerator.net/) или [favicon.io](https://favicon.io/) — сервис сгенерирует все размеры и даст архив.

3. **Из командной строки (ImageMagick, Inkscape)**  
   - ImageMagick:  
     `convert -background none -resize 32x32 favicon.svg favicon-32x32.png`  
   - Inkscape:  
     `inkscape favicon.svg -w 32 -h 32 -o favicon-32x32.png`  
   Повторить для 16, 180, 192, 512 и сохранить под именами из таблицы выше.

## Куда класть файлы

Все файлы — в каталог:

```
static/images/
```

После добавления файлов перезагрузить страницу (при необходимости — очистить кэш браузера или сделать hard refresh).

## Что уже сделано в проекте

- В `templates/base.html` добавлены `<link>` на все перечисленные иконки.
- Если какого-то PNG ещё нет, браузер просто не найдёт файл; SVG-фавикон продолжит работать.
- По мере готовности добавляйте файлы в `static/images/` с именами из таблицы — дополнительный код не нужен.

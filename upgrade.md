**Как запустить (Django, не Streamlit):**
```bash
cd /Users/Yaroslav/Documents/dev/portal-shop-clone
source venv/bin/activate
python manage.py runserver 0.0.0.0:8001
```
Открыть в браузере: http://127.0.0.1:8001  
(Порт 8000 часто занят Docker — используем 8001.)

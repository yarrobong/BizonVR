Технологическая база

Инструмент, который делает компактный формат возможным

KAT Walk C2 Core Ключевой инструмент, на котором держится логика компактного формата

Основа безграничного перемещения

KAT Walk C2 Core создаёт для игрока ощущение непрерывного движения внутри VR-пространства без необходимости в большой физической арене.

Минимальный размер игрового места

Габариты площадки: 1,1 х 1,1 метра. Игроки перемещаются по безграничному пространству, оставаясь на месте.

Позволяет снизить затраты на помещение

Удешевляет запуск, снижает расходы. Позволяет менять локации менее болезненно.

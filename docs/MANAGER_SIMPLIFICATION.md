# Упрощение менеджерского портала

## Текущая проблема

Форма создания заказа содержит **50+ полей**, многие из которых дублируются или не нужны на первом шаге. Менеджер вынужден вводить много данных, даже для простой сделки.

## Рекомендуемый минимальный сценарий

### 1. Создание сделки «Продажа под заказ»

**Обязательно только:**
- ФИО
- Телефон
- Город
- 1+ товар (выбор + количество + цена продажи)
- Адрес ПВЗ СДЭК (если доставка СДЭК)
- Что хочет клиент (1 строка)
- Откуда заказываем (1 строка)
- Поставщик или агент (1 строка)

**Автоподстановка:**
- Ответственный = текущий пользователь
- Дата = сейчас
- Источник = Сайт
- Способ доставки = СДЭК ПВЗ
- Закупочная цена = 0 (можно заполнить позже)
- Предоплата = 0

**Скрыть до «Расширенных настроек»:**
- Дедлайн, комментарий по заказу
- Доп. телефон, Telegram
- Полный адрес доставки (если не курьер)
- Город отправки/получения (вывести из склада/клиента)
- Статус заказа (система выставит «Новая заявка»)
- Плановая дата закупки, ожидаемая дата поступления
- Все поля Avito, трейд-ин, юр. лица

### 2. Создание закупки

**Минимум:**
- Связать со сделкой (автоматически из очереди «Запустить закупку»)
- Добавить позиции из заказа (кнопка «Взять из сделки»)
- Дата, поставщик
- Создать → сразу «Заказано»

**Скрыть:** Сумма, валюта, комментарий (опционально)

### 3. Создание груза

**Минимум:**
- Номер груза (можно автогенерировать: CARGO-YYYY-NNN)
- Связать с закупкой
- Склад назначения
- ETA (опционально)

**Скрыть:** Комментарий

### 4. Отслеживание груза

**Показать:**
- Статус (Создан → В пути → Прибыл → Принят)
- Кнопки смены статуса (без формы)
- Трек-номер (если есть)
- Позиции и количество принято

### 5. Управление сделкой

**Одна карточка с вкладками:**
- Основное (клиент, товары, суммы)
- Закупка (ссылка на закупку, статус)
- Груз (ссылка на груз, статус, ETA)
- Документы
- Отгрузка

**Действия одной кнопкой:**
- «Предоплата получена» → обновить prepayment_amount
- «Заказ у поставщика» → создать закупку из позиций
- «Груз в пути» → создать груз из закупки
- «Товар поступил» → принять груз
- «Готов к отправке» → перейти к отгрузке

## Реализация

1. **Форма «Быстрое создание»** — отдельный шаблон/вид с 8–10 полями.
2. **Сценарий-зависимые поля** — показывать только релевантные для выбранного типа.
3. **Кнопки «Из сделки»** — в формах закупки и груза подставлять данные из выбранной сделки.
4. **Статусы одним кликом** — вместо выпадающего списка — кнопки «Получена предоплата», «Заказано» и т.д.

## Команды

```bash
# Очистить все данные портала
python manage.py clear_manager_data --confirm

# Создать тестовую сделку (после очистки)
python manage.py seed_manager_test_deal
```

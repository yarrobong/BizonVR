# Техническое задание на разработку сайта BizonVR

## 1. Общая информация
**Название проекта:** BizonVR  
**Тип проекта:** Интернет-магазин  
**Основной язык:** Русский  
**Целевая аудитория:** Покупатели VR оборудования и аттракционов

## 2. Функциональные требования

### 2.1 Каталог продукции
- Отображение товаров в виде карточек
- Фильтрация по категориям:
  - VR оборудование
  - VR аттракционы  
  - Трейдин устройства
- Постраничная навигация
- Сортировка товаров

### 2.2 Детальная страница товара
- Полная информация о товаре
- Изображения товара
- Характеристики
- Цена
- Кнопка "Добавить в корзину"

### 2.3 Корзина товаров
- Отображение в модальном окне
- Возможность изменения количества
- Удаление товаров
- Подсчет общей суммы
- Оформление заказа

### 2.4 Оформление заказа
- Форма с полями для контактной информации
- Выбор способа доставки
- Подтверждение заказа

### 2.5 Платежная система
- Оплата по СБП, банковской карте и через менеджера для юрлиц
- Обработка платежей
- Статусы заказов

## 3. Технические требования

### 3.1 Стек технологий
- **Backend:** Django (Python)
- **Database:** PostgreSQL
- **Frontend:** 
  - Tailwind CSS
  - HTMX (для SPA-подобного поведения)
  - Alpine.js (для интерактивности)
- **Infrastructure:**
  - Gunicorn
  - Nginx (веб-сервер)

### 3.2 Архитектурные требования
- Принципы ООП
- Принцип DRY (Don't Repeat Yourself)
- Маппинг данных при необходимости
- Безопасность кода
- Следование лучшим практикам разработки

### 3.3 Фронтенд архитектура
- SPA-подобное поведение с использованием HTMX
- Динамическая загрузка контента без полной перезагрузки страницы
- Модальные окна для корзины и других элементов
- Адаптивный дизайн

## 4. Требования к безопасности
- Защита от SQL-инъекций
- Защита от XSS-атак
- Валидация всех входных данных
- Безопасное хранение паролей
- Защита платежных данных

## 5. Структура проекта
```
bizon/
├── core/ (основное приложение Django)
├── products/ (модели и представления товаров)
├── cart/ (корзина)
├── orders/ (заказы)
├── payments/ (платежи)
├── templates/ (шаблоны Django)
├── static/ (статические файлы)
│   ├── css/ (Tailwind)
│   └── js/ (Alpine.js, HTMX)
├── deploy/
│   └── nginx.conf.example
├── database/
│   └── migrations/
├── manage.py
└── requirements.txt
```

## 6. Этапы разработки
1. Настройка окружения и инфраструктуры
2. Создание базы данных и моделей
3. Разработка основного функционала каталога
4. Реализация корзины и заказов
5. Интеграция платежной системы
6. Фронтенд разработка с использованием HTMX
7. Тестирование и оптимизация
8. Деплой и запуск

## 7. Критерии приемки
- Все функциональные требования реализованы
- Код соответствует указанным принципам
- Сайт работает корректно на всех устройствах
- Производительность на приемлемом уровне
- Безопасность подтверждена тестированием

## 8. Дополнительные требования
- Полная локализация на русский язык
- Минимальное количество перезагрузок страниц
- Быстрая загрузка контента
- Удобная навигация
- Интуитивно понятный интерфейс
